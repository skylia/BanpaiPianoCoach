LET'S PLAY

接好琴，剩下的慢慢来

1

连接琴键

用 USB 数据线连接琴的 USB TO HOST 与电脑。在 Chrome / Edge 打开此 HTTPS 网站，点击「连接琴键」并允许设备访问。Mac 也可以使用。

2

选谱，选一小段

在曲谱库选择练习。可以分左右手、设置小节范围、降低速度、放大谱面；「专注看谱」会扩大阅读区域。

3

四拍之后，开始弹

练习时高亮与游标会跟随进度。结束后可查看逐音对比、回听与练习建议。模拟练习随时可用。

导入和编辑谱子

支持本应用 JSON 和标准 MIDI 0 / 1 文件。MIDI 导入可选择轨道、左右手和量化精度；乐谱排版由音符数据重建，原谱的连线、表情、指法通常不在 MIDI 里。支持图形化新增、拖动、修改音符及休止，保存后即可跟练。

当前分析的范围

本地规则比较目标音高与起音时刻，支持双手与和弦；暂不评价手型、踏板、音色或音乐表现力，阶段报告可选用 DeepSeek，仅发送你确认的摘要。音频内录线、录音和照片识谱尚未接入。已完成一次实琴流程测试，不同琴型仍以实际连接为准。

本机数据

我的曲谱与练习记录存于本浏览器，不会跨设备同步。成长进度提供 1–10 级自主学习清单、练习补记和曲目计划；学习进度不等于考级认证。换电脑或清除网站数据前，请分别导出曲谱备份和进度备份。首版旧记录仍保留，可查看为旧版记录。
