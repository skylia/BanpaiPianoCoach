# 可导入示例

- `beginner-study.json`：v2 完整曲谱，C 大调、4/4、72 BPM、两小节；9 个发声音符与 1 个显式休止，含左右手及指法。
- `beginner-study.mid`：同一段音乐，标准 MIDI 类型 1；右手和左手分别为独立轨道。

在网站「我的曲谱 → 导入谱子」选择任一文件，预览后保存。MIDI 预览时可根据 `Right hand · 右手` 和 `Left hand · 左手` 轨名指定手别。

JSON 保留谱子标题、元数据、指法和显式休止。MIDI 保留发声音符的音高、起音、时值、速度、调号与拍号；休止从时间空隙重新排版，指法不会恢复。这段内容为半拍原创导入示例，不是哈农或车尔尼原谱。
