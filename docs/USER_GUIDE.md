# 半拍使用手册

[返回项目首页](../README.md)

适用于 0.5 版。面向钢琴入门至业余进阶学习者的电脑端 Web 练琴工具。连接电钢琴或使用模拟输入，在五线谱上选择一段练习，录下琴键事件，查看错音、漏音、多音和节奏反馈；支持自编曲谱、JSON / MIDI 导入、本地备份，以及 1–10 级学习路线、长期练习统计和曲目计划。

**逐音反馈在浏览器本机计算。可选的 DeepSeek 阶段报告仅在手动确认后发送统计摘要；不发送录音、逐音事件或自由文字笔记。**

## 在自己的 Mac / Windows 电脑上运行

安装 Node.js 22 或更新版本，解压源码，在含有 `package.json` 的项目目录打开终端：

```bash
npm start
```

用桌面版 Chrome 或 Edge 打开 `http://localhost:3000`。基础练习无需 API Key、数据库或 `npm install`；音符字体和 VexFlow 谱面组件已包含在源码中。不要直接双击 `public/index.html`。

| 命令 | 用途 |
| --- | --- |
| `npm start` | 启动本地开发服务器，默认端口 3000 |
| `npm test` | 运行谱子、MIDI、演奏分析、输入及谱面准备等自动化测试 |
| `npm run build` | 将完整静态网站生成到 `dist/` |

Mac 可用 `PORT=3001 npm start` 更改端口。开发服务器仅监听 `127.0.0.1`。DeepSeek Key 由该本机服务读取。网站的私密访问控制由托管平台提供，不能依靠链接难猜或 `noindex` 代替登录验证。

## 不接琴也能先试一遍

在练习室选择曲谱，点击「体验模拟练习」。系统会倒数并生成模拟演奏；固定速度模式包含少量预设失误，跟弹模拟使用正确音符，结束后显示反馈。模拟记录有单独标签，默认不计入真实练习统计。

也可选择「使用屏幕 / 电脑键盘」，再点击「开始练习」：

- 白键使用 `A S D F G H J K`，黑键使用 `W E T Y U`。
- `Z / X` 或琴键区的八度按钮切换音区。
- 鼠标、触屏可直接按页面琴键；多音和双手练习推荐真实琴键输入。

屏幕琴键音域与手别选择是两回事：选择「仅左手」改变目标声部，演奏左手音时仍需切到相应音区。

## Mac 连接电钢琴

将琴的 **USB TO HOST** 接口用可传数据的 USB 线连接 Mac。琴端是 USB-B 方口、电脑端是 Type-C 时，可使用 USB-C → USB-B 数据线，或现有 USB-A → USB-B 线配数据转接头。接口形状以琴本身的标识为准。

打开琴，在桌面版 Chrome / Edge 中访问 HTTPS 私有网站或 `http://localhost:3000`，点击「连接琴键」，允许浏览器访问音乐设备。弹下一个音，确认设备状态、输入音名与琴键高亮都有响应，再开始录制。Mac 不需要安装 Windows 驱动；设备仍无法识别时应检查线材与厂商针对当前 macOS 提供的说明。

Web MIDI 需要安全上下文和浏览器授权；普通局域网 HTTP 地址不等同于 `localhost`。权限说明参考 [Chrome 官方说明](https://developer.chrome.com/blog/web-midi-permission-prompt) 与 [Web MIDI 文档](https://developer.mozilla.org/en-US/docs/Web/API/Web_MIDI_API)。Safari 不作为本版实琴连接的目标浏览器。

**只有音频功能的内录线、琴的耳机口 / AUX OUT 接声卡，传来的都是声音，不能直接提供琴键音符。** 本版尚无麦克风采集、音频转谱、照片识谱或音频文件分析。USB 同时支持音频和 MIDI 的设备，只有其 MIDI 通道会被本版使用。无需先录成 MIDI 文件；实时连接成功后可以直接弹。

## 曲谱与跟练

分级曲库覆盖 **1–10 级**，每级保留至少 10 个条目，三级另有克列门蒂 Op.36 No.1 三个完整乐章。乐曲逐首关联真人演奏来源；原有缺少对应演奏的自编入门旋律退出入口，改用有原谱与演奏对应的入门曲目。具体曲目与来源以 [曲目表](../REPERTOIRE.md) 和 [演奏资源清单](../research/demos/) 为准。原有记录、曲谱快照和计划继续保留。

「基本功训练」取代旧版基础练习入口，按哈农原条号与训练片段筛选；音阶、琶音、分解和弦等归在对应原谱条目内。基本功使用标准音符示范，不要求真人录音。哈农条号不换算为考级等级；分级乐曲全部是通用参考难度，需由老师结合版本、速度和学生情况选用。

谱面显示左右手五线谱，默认 **80%**，可在 **50%–180%** 之间缩放并记住本机选择；点击「默认」恢复 80%。桌面谱面占满练习区宽度，随屏幕尺寸和音符密度排成多行；「专注看谱」进一步扩大区域。自动跟谱尽量同时保留当前行与下一行，换行只滚动谱面；放大到两行无法容纳时优先保留当前行。谱面右上方的「谱面转录说明」可展开查看排版限制。

可显示指法 / 音名；选择「仅右手」「仅左手」或双手，设定小节范围、速度与重复次数，再听示范或开始练习。示范播放、暂停、继续和停止按钮位于谱面上方。启用自动跟谱时，开始示范或实琴练习会将阅读区域带到眼前。循环按所选段落重复，每一遍独立保存记录；下一遍仍有四拍倒数。

「评价标准」和「练习方式」独立选择：

| 选择 | 行为 |
| --- | --- |
| 乐曲 · 允许速度处理 | 跟随局部演奏速度，关注主干音、音符间隔比例、明显停留与 MIDI 力度变化；以问题位置和文字为主 |
| 基本功 · 严格节拍 | 按所选 BPM 检查起音均匀性、错漏音和和弦同步，保留量化成绩 |
| 完整演奏 | 乐曲由自己点击「结束这一遍」；严格节拍按目标时长结束 |
| 跟弹 · 弹对再前进 | 弹对当前主干音／和弦再前进，记录错误尝试与纠错等待；节奏依所选评价标准计算 |

和弦需一次弹齐；单纯停顿不会重复累计错误。克列门蒂第二乐章第 3、21、25 小节的右手颤音允许在主音和辅助音间交替、以任一音起奏；左手仍需对应谱面。其他乐曲装饰音只有人工标注的片段会按这一规则处理，MIDI 不会自动推断标记。

刷新后回到上次曲目和准备状态，保留速度、声部、小节、练习方式、评价标准、节拍器、循环次数、音名／指法显示、自动跟谱与谱面位置。摘要显示本曲近 7 天次数／时长、上次设置和最近问题，以及今天与本周时长；谱面位置不代表已掌握。

已授权的 MIDI 设备自动连接，优先上次使用的琴；主动选择屏幕键盘后不会被热插拔抢回。首次使用和权限撤销仍需手动授权。

「真人演奏」显示演奏者、来源、许可与版本覆盖。内置或自己导入的音频可暂停、拖动、0.5–1.25× 保持音高变速，设 A／B 点循环；慢放音质需结合实际聆听判断。视频资源统一使用 Bilibili，对应到具体单曲、分 P 或时间；没有视频时使用真人音频。Bilibili 演奏使用其播放器功能，需要联网，部分内容可能需要登录，只在点击播放／打开来源时加载。尚未核对小节时间表的录音不显示同步游标；真人版本的反复和装饰音可能与转录谱不同。

本机录音每曲一份、每份不超过 100 MB，支持 MP3、M4A、WAV、OGG、FLAC 等浏览器可解码格式。重新导入会替换当前曲目的录音；原文件应自行保留，录音不含在进度备份里。

「标准音符示范」继续支持分手、分段、暂停和回听，用于核对音符。练习开始、切换曲目或播放另一种示范时，当前页面的演奏播放器会停止。真人演奏不作为评分模板。

「关于这份谱子」提供来源与版本信息。哈农新转录与历史两个 Mutopia 条目的许可分别说明在 [资源来源](../SOURCES.md) 和 [哈农来源](../research/hanon/) 中。

五线谱适合练习阅读，不是专业出版排版器。复杂复调以共用符干、和弦及延音线重建；谱面显示按三十二分网格排版，原始目标时值仍用于播放和分析。原谱的分声部、装饰音、表情、连奏线或反复结构不会由 MIDI 自动还原。出现排版提示时应核对原谱，尤其是未量化的演奏 MIDI。

## 自己写谱与导入

「我的曲谱 → 新建曲谱」打开图形编辑器。先填曲名、速度、拍号与调号，选择左右手，在钢琴卷帘网格点击添加音符或休止；拖动音符改变音高与位置。同一拍可以添加多个音符组成和弦。

右侧可修改音高、时值和指法。支持增添小节、复制本手当前小节、删除、撤销 / 重做；选中音符后可用方向键微调、Delete 删除。顶部五线谱随修改预览。内置谱通过「编辑一个副本」进入编辑器，保存为自定义曲谱，不会覆盖内置源谱。

个人曲谱最多 100 首；单曲 JSON 不超过 2 MB，曲库备份不超过 64 MB，MIDI 不超过 16 MB；每首最多 4096 音符 / 休止与 256 小节。

导入入口支持选择文件、拖放 `.json` / `.mid` / `.midi` 或粘贴 JSON；先预览，再保存。源码中的 [beginner-study.json](../examples/beginner-study.json) 和 [beginner-study.mid](../examples/beginner-study.mid) 是可直接导入的同一段两小节双手示例。JSON 包含指法与休止，MIDI 包含音符、手别轨道、速度和拍号；MIDI 不携带本应用的指法和完整来源元数据。

| 格式 | 支持与边界 |
| --- | --- |
| JSON | 本应用 v2 谱子，或旧版 `pitches` / `lengths`；校验数值、音域、时值、ID、大小等；单曲 JSON 最大 2 MB，曲库备份最大 64 MB |
| MIDI | 标准 MIDI 类型 0 / 1、PPQ 拍计时、变长数字、running status、Note On / Off、速度和拍号 |
| MIDI 轨道 | 可预览轨道、选择导入声部并指定左右手；自动分手按中央 C 以下归左手，需人工核对 |
| MIDI 量化 | 默认四分之一拍，即十六分音符；也可选择其他精度或不量化 |
| 曲谱容量 | 每首最多 4096 个音符 / 休止符、256 小节、88 键钢琴音域 |
| 不支持的 MIDI | 类型 2、SMPTE 时间码；换拍只保留首个拍号并提示，转调同理 |

MIDI 解析会提示被忽略的打击乐、钢琴音域以外的音、踏板及不完整配对。缺抬键的音按轨道末尾截断并提示。自动量化可能改变演奏细节；保存前请核对。导入长度以所选音符结尾补齐整小节，不保留文件末尾的纯空轨时长。详细模型与接口见 [ARCHITECTURE.md](../ARCHITECTURE.md)。

可从当前谱子的来源卡导出 JSON 或 MIDI。从自定义曲库迁移时优先用 JSON，以保留精确数据、指法与来源说明。修改变速 MIDI 的全曲 BPM 时，图形编辑器会将曲谱改为匀速；仅调整练习速度则按比例缩放既有变速。

## 反馈与练习记录

乐曲反馈以问题小节和文字为主，辅助百分比收在详情里；基本功保留音符准确率和固定节拍指标。支持双手和弦的无序匹配，多音会影响结果。新版乐曲、新版基本功和旧版记录分组，AI 摘要和 PDF 也保留这些区分。MIDI 力度只代表琴键输入，不等同于实际响度或表达质量。当前未做设备延迟校准。

少于 3 个对齐音不计算节奏分数；没有收到音符时不生成虚构成绩。提前结束会说明未完成内容。切到后台或设备断开会终止当前采集，保留已录内容。回听使用浏览器中的钢琴采样或合成音色，不是电钢琴原始录音。

每遍最多采集 8192 个实际按键事件，达到上限时结束采集。

当前不评价手型、指法正确性、踏板、触键质量、音色或音乐表现力。指法显示是谱面提示，不代表系统能看到你使用的手指。

## 成长进度与 1–10 级学习路线

左侧「成长进度」包含四页：

- **练习概览**：7 / 30 / 90 天时长、自动采集与补记区分、练习天数、连续天数、每日音符表现及 12 周练习日历。点击日期可查看当天记录。
- **1–10 级路线**：每级 12 项，共 120 项自主学习目标；分基本练习、练习曲、复调与声部、乐曲表达、视奏与读谱、听觉与乐理。每项可记为还未开始、正在练习、等待复核、已经掌握，并留下本人评估或老师反馈。
- **AI 阶段报告**：近 7 / 30 天，预览摘要、手动生成、保存与导出。
- **我的练习计划**：关联应用曲谱或纸谱，安排学习阶段、目标速度、左右手及下一步。可以从计划直接打开对应曲谱练习，也可在练习室「关于这份谱子」中加入计划。

这是半拍独立整理的学习路线，**不是官方考级大纲或通过认证**。哈农条号与 599 教材进度不直接换算级别，分级曲库是通用练习材料；实际备考曲目与要求需按选定机构、教材及老师安排核对。参考来源和口径详见 [LEARNING-ROADMAP.md](../LEARNING-ROADMAP.md)。

没有接琴时可以点击「补记练习」，记日期、分钟、练习内容与笔记。补记只影响时长和练习天数，不生成准确率。每周目标和目标等级可自行调整。首次使用没有虚构个人成绩；「看看进度示例」仅在内存展示，退出后不留下个人记录。

曲目计划的“近期表现可复核”要求：相同谱子内容和声部、全曲范围、达到目标速度，近 30 天最近 3 次完整采集均达到 95% 音符准确率和 85% 起音合拍率，至少分布在 2 天。它只适用于同一分析版本的严格节拍记录，乐曲自由速度与跟弹不用于此自动证据。它包含屏幕琴键采集，不会自动完成等级清单或判断音乐表现力。

## DeepSeek 近 7 / 30 天报告

1. 将根目录 `.env.example` 复制为 `.env`（已有 `.env` 时直接编辑，不要覆盖）。
2. 在 `.env` 中填写 `DEEPSEEK_API_KEY=你的Key`，保持 `DEEPSEEK_MODEL=deepseek-flash` 或填写你账户可用的模型。
3. 停止原服务并重新执行 `npm start`；只刷新网页不会重新读取 Key。
4. 进入「成长进度 → AI 阶段报告」，选择 7 或 30 天，点击「整理本机练习数据」。展开摘要检查内容，再点击「发送摘要并生成报告」。

Key 不写入网页、浏览器存储或 Git，`.env` 已被忽略。本地服务固定请求 [DeepSeek Chat Completion](https://api-docs.deepseek.com/api/create-chat-completion/)，按账户计费；不自动定时调用。请求失败会区分配置、余额、限流和网络问题。

发送内容包括：当前和前一等长周期的时长／练习日数／完整练习指标、实琴与屏幕来源数量、同曲同手同段同速度的练习趋势、仍有明细的错误小节、目标等级与计划状态。模拟数据排除，补记只有时长。不同输入来源与分析版本不混作同组进步。原始录音、逐音事件、笔记和 Key 不属于发送摘要。模型不能据此判断手型、音色、踏板或是否通过考级。

报告在当前浏览器保存。打开新报告或「以前的阶段报告」，点击 **导出 PDF**，即可下载 A4 中文报告：日期、关键练习数据、分段点评、练习依据附页与页码。支持中文选择复制和打印；长报告自动分页。历史报告无需重新调用 AI，缺少依据快照的旧报告仍可导出原文，不补造统计数字。

「备份报告数据（JSON）」保留原始正文及发送依据，适合数据备份。PDF 只在本机排版，不上传报告，不再次调用 DeepSeek；首次导出按需加载约 10 MB 的完整中文字体，日常练习不加载此资源。首次没有练习数据时会提示先练习／补记。本次开发使用模拟接口验证，未使用真实 Key 发起付费调用。

## 示范与屏幕琴键音色

点击「听一遍示范」后，按钮切换为「暂停示范」；暂停会保留声音和游标的播放位置，再点「继续示范」接着听。旁边的「停止示范」用于结束播放，下次从所选范围开头开始。播放时间随暂停冻结，长音按采样位置续播；暂停时放大或缩小仍保留游标。切换曲谱、声部、小节范围或速度会结束旧播放。页面切到后台自动暂停，回来后手动继续。「回听本次」同样支持暂停和继续。

默认使用本地 Salamander Yamaha C5 三角钢琴采样，提供「三角钢琴」「温暖钢琴」「原合成音（对比）」切换。30 个 MP3 采样约 2 MB，首次播放加载并解码；之后复用。支持按键释放与复音，采样不可用时回退合成音。实琴仍由琴自身发声，不叠加软件音。

谱面下方的「示范力度」默认选择「按曲谱强弱」，根据来源 MIDI 的按键力度播放；可切换「均匀力度（对照）」再听一遍，切换时会结束当前示范。93 个来源 MIDI 条目中，30 个含力度变化，63 个为固定力度；一级入门曲按各自原谱转录，不凭空编造演奏力度，界面会说明。可先用三级《坦诉 · Op.100 No.1》对照试听。克列门蒂 Op.36 No.1 的三个源文件均为固定力度，未人为添加渐强渐弱。个人 MIDI 导入、JSON 保存及 MIDI 导出也保留逐音力度；「回听本次」使用录下的按键力度，不受示范对照开关影响。

标准音符示范恢复的是来源已有的强弱音量。单力度层采样尚不能还原不同触键的音色变化，亦未据此补写原谱的 p / f、呼吸、句尾处理、踏板或自由速度。真人演奏入口可用于聆听完整表达；两种示范都不会被拿来要求你逐毫秒、逐力度模仿，评价标准见上文。

## 保存、备份与迁移

自定义谱子和新版练习记录存放在当前网站、当前浏览器的 **IndexedDB**，最近 100 次详细音符记录可在「练习记录」中查看。从 0.3 起另外保留长期摘要，超过 100 次后累计时长和成长统计仍保留；升级前已经删除的旧记录无法找回。旧版 `localStorage` 中的有效记录会一次性迁入新版记录，标记为旧版；原数据在清空历史前仍保留。界面偏好可能使用浏览器本地设置；没有云端账号数据库或跨设备同步。

换电脑、从部署地址转到 `localhost`、换浏览器配置或清理网站数据前：

1. 在曲谱库点击「备份我的全部谱子」，保留 JSON；也可逐首导出 JSON。
2. 在成长进度底部点击「备份进度」，保留目标、等级清单、计划、笔记和长期摘要。
3. 需要保留完整音符的某次练习，仍需从反馈单独导出练习 JSON。
4. 阶段报告在 AI 页面单独导出：PDF 用于阅读／打印，JSON 备份正文和发送依据。最多保存最近 20 份，不含在进度备份中。
5. 在新地址分别导入曲谱备份、恢复进度；重复恢复按记录 ID 去重。恢复前会说明设置替换范围，已有摘要以本机内容为准。

进度备份最多 128 MB / 200000 条摘要；导出前同样校验，避免生成自身无法导入的文件。曲谱恢复改变 ID 时，计划会按相同音乐内容尝试重新关联；不唯一或未导入对应谱时提示待关联。完整音符记录不包含在进度备份中，单次练习 JSON 仍用于离线留存，暂不支持批量恢复成详细历史。

源码包含程序和内置曲谱，不包含浏览器里的个人练习记录。私有部署网站与 `localhost` 属于不同来源，无法自动共享 IndexedDB。备份文件应另行妥善保存，导出曲谱也不会迁移浏览器设备权限。

Git 忽略个人进度备份 `Banpai-Learning-Progress-*.json`、单次练习 `Banpai-Practice-*.json`、AI 报告 `Banpai-AI-*.json` / `Banpai-AI-*.pdf` 和个人曲库备份 `Banpai-My-Scores*.json`。若重命名备份或保存其他个人文件，请放在项目根目录的 `private-data/` 中，该目录整体忽略；`.env` 中的 Key 也不会提交。浏览器中的原始进度不受代码提交影响。

逐音分析在浏览器中完成。只有手动生成 AI 报告时，本机服务才向 DeepSeek 发送预览的统计摘要；没有第三方分析 SDK。托管平台的身份验证及普通访问日志属于网站基础设施。

## 验证与部署

本版的自动化测试数量与浏览器验收结果见 [VALIDATION.md](../VALIDATION.md)。执行 `npm test` 复跑自动化测试，覆盖曲谱校验、JSON / MIDI 导入导出、力度、跟弹、变速与分段、和弦与错漏音、输入事件、谱面准备和 PDF 导出等。浏览器验证用于检查实际操作流程与布局。**2026-09-22 用户反馈：实际钢琴连接后的练习流程通过**，琴型与浏览器版本未记录；该反馈及模拟 Web MIDI 验证不等于确认所有 Mac、驱动与琴型均已兼容。

运行 `npm run build` 后，把整个 `dist/` 部署到 HTTPS 静态托管的独立域名根目录，并保持平台登录 / 成员访问控制。内置资源无需外部 CDN；源码可独立本地运行。静态部署只提供本机练习与统计，AI 报告需要 `npm start` 启动的本地 API。

VexFlow 及 Bravura 资源位于 `public/vendor/`，许可证为 [VEXFLOW-LICENSE.txt](../public/vendor/VEXFLOW-LICENSE.txt)。Noto Sans SC 字体许可证位于 [OFL.txt](../public/fonts/OFL.txt)。曲谱数据的来源许可单独列于 [SOURCES.md](../SOURCES.md)，不与软件依赖许可证混为一谈。

PDF 导出的 pdf-lib、fontkit 与完整中文字体也随源码提供，固定版本、来源和许可见 [PDF-DEPENDENCIES.md](../public/vendor/PDF-DEPENDENCIES.md)。无需运行时安装依赖或访问外部 CDN。
