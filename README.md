# 半拍 · 私人练琴室 0.3

面向钢琴初学者的电脑端 Web 练琴测试版。连接电钢琴或使用模拟输入，在五线谱上选择一段练习，录下琴键事件，查看错音、漏音、多音和节奏反馈；支持自编曲谱、JSON / MIDI 导入、本地备份，以及 1–5 级学习路线、长期练习统计和曲目计划。

**反馈由浏览器内的规则算法生成。产品方向是 AI 练琴教练，但这一版没有调用大语言模型，没有音频识别，也不会把演奏数据上传到云端分析。**

## 在自己的 Mac / Windows 电脑上运行

安装 Node.js 22 或更新版本，解压源码，在含有 `package.json` 的 `banpai` 目录打开终端：

```bash
npm start
```

用桌面版 Chrome 或 Edge 打开 `http://localhost:3000`。无需 API Key、数据库或 `npm install`；音符字体和 VexFlow 谱面组件已包含在源码中。不要直接双击 `public/index.html`。

| 命令 | 用途 |
| --- | --- |
| `npm start` | 启动本地开发服务器，默认端口 3000 |
| `npm test` | 运行谱子、MIDI、演奏分析、输入及谱面准备等自动化测试 |
| `npm run build` | 将完整静态网站生成到 `dist/` |

Mac 可用 `PORT=3001 npm start` 更改端口。开发服务器监听 `0.0.0.0`，源码不含独立账号认证；本地服务器仅供受信任环境使用。网站的私密访问控制由托管平台提供，不能依靠链接难猜或 `noindex` 代替登录验证。

## 不接琴也能先试一遍

在练习室选择曲谱，点击「体验模拟练习」。系统会倒数并生成带少量预设失误的演奏，结束后显示反馈。模拟记录有单独标签，默认不计入真实练习统计。

也可选择「使用屏幕 / 电脑键盘」，再点击「开始练习」：

- 白键使用 `A S D F G H J K`，黑键使用 `W E T Y U`。
- `Z / X` 或琴键区的八度按钮切换音区。
- 鼠标、触屏可直接按页面琴键；多音和双手练习推荐真实琴键输入。

屏幕琴键音域与手别选择是两回事：选择「仅左手」改变目标声部，演奏左手音时仍需切到相应音区。

## Mac 连接电钢琴

将琴的 **USB TO HOST** 接口用可传数据的 USB 线连接 Mac。琴端是 USB-B 方口、电脑端是 Type-C 时，可使用 USB-C → USB-B 数据线，或现有 USB-A → USB-B 线配数据转接头。接口形状以琴本身的标识为准。

打开琴，在桌面版 Chrome / Edge 中访问 HTTPS 私有网站或 `http://localhost:3000`，点击「连接琴键」，允许浏览器访问音乐设备。弹下一个音，确认设备状态、输入音名与琴键高亮都有响应，再开始录制。Mac 不需要安装 Windows 驱动；设备仍无法识别时应检查线材与厂商针对当前 macOS 提供的说明。

Web MIDI 需要安全上下文和浏览器授权；普通局域网 HTTP 地址不等同于 `localhost`。权限说明参考 [Chrome 官方说明](https://developer.chrome.com/blog/web-midi-permission-prompt) 与 [Web MIDI 文档](https://developer.mozilla.org/en-US/docs/Web/API/Web_MIDI_API)。Safari 不作为本版实琴连接的目标浏览器。

**只有音频功能的内录线、琴的耳机口 / AUX OUT 接声卡，传来的都是声音，不能直接提供琴键音符。** 本版尚无麦克风采集、音频转谱、照片识谱或音频文件分析。USB 同时支持音频和 MIDI 的设备，只有其 MIDI 通道会被本版使用。无需先录成 MIDI 文件；实时连接成功后可以直接弹。

## 曲谱与跟练

当前内置 9 条练习，教材曲目按来源逐音录入；没有宣称收录整本教材。

| 内容 | 收录范围 |
| --- | --- |
| 哈农第 1、2 条 | 全部音符，各反复段只弹一遍 |
| 车尔尼 Op.599 第 1 条 | 全部 16 小节，各反复段只弹一遍 |
| 车尔尼 Op.599 第 2 条 | 前 8 小节节选 |
| 欢乐颂、小星星 | 右手入门旋律节选 |
| 五指小步走、双手五指、C 大调音阶 | 半拍原创练习编排 |

谱面显示左右手五线谱，可放大、显示指法 / 音名、自动跟谱和进入专注看谱。选择「仅右手」「仅左手」或双手，设定小节范围、速度与重复次数，再听示范或开始练习。循环按所选段落重复，每一遍独立保存记录；下一遍仍有四拍倒数。

「关于这份谱子」提供来源与版本信息。教材录入保留所标版本的音高和时值；网站会重新排版。哈农省略表情与原版指法，599 的指法来自所说明的校订版本。哈农转录依据 Steve Taylor / Javier Ruiz-Alma 的 Mutopia 版本，这两个条目的改编数据使用 CC BY-SA 4.0；599 根据所列公版底本独立录入。来源、许可与改动范围详见 [SOURCES.md](./SOURCES.md)，转载曲谱数据时须保留相应署名与许可说明。

五线谱适合练习阅读，不是专业出版排版器。复杂复调以共用符干、和弦及延音线重建；谱面显示按三十二分网格排版，原始目标时值仍用于播放和分析。原谱的分声部、装饰音、表情、连奏线或反复结构不会由 MIDI 自动还原。出现排版提示时应核对原谱，尤其是未量化的演奏 MIDI。

## 自己写谱与导入

「我的曲谱 → 新建曲谱」打开图形编辑器。先填曲名、速度、拍号与调号，选择左右手，在钢琴卷帘网格点击添加音符或休止；拖动音符改变音高与位置。同一拍可以添加多个音符组成和弦。

右侧可修改音高、时值和指法。支持增添小节、复制本手当前小节、删除、撤销 / 重做；选中音符后可用方向键微调、Delete 删除。顶部五线谱随修改预览。内置谱通过「编辑一个副本」进入编辑器，保存为自定义曲谱，不会覆盖内置源谱。

个人曲谱最多 100 首；单曲 JSON 不超过 2 MB，曲库备份不超过 64 MB，MIDI 不超过 16 MB；每首最多 4096 音符 / 休止与 256 小节。

导入入口支持选择文件、拖放 `.json` / `.mid` / `.midi` 或粘贴 JSON；先预览，再保存。源码中的 [beginner-study.json](./examples/beginner-study.json) 和 [beginner-study.mid](./examples/beginner-study.mid) 是可直接导入的同一段两小节双手示例。JSON 包含指法与休止，MIDI 包含音符、手别轨道、速度和拍号；MIDI 不携带本应用的指法和完整来源元数据。

| 格式 | 支持与边界 |
| --- | --- |
| JSON | 本应用 v2 谱子，或旧版 `pitches` / `lengths`；校验数值、音域、时值、ID、大小等；单曲 JSON 最大 2 MB，曲库备份最大 64 MB |
| MIDI | 标准 MIDI 类型 0 / 1、PPQ 拍计时、变长数字、running status、Note On / Off、速度和拍号 |
| MIDI 轨道 | 可预览轨道、选择导入声部并指定左右手；自动分手按中央 C 以下归左手，需人工核对 |
| MIDI 量化 | 默认四分之一拍，即十六分音符；也可选择其他精度或不量化 |
| 曲谱容量 | 每首最多 4096 个音符 / 休止符、256 小节、88 键钢琴音域 |
| 不支持的 MIDI | 类型 2、SMPTE 时间码；换拍只保留首个拍号并提示，转调同理 |

MIDI 解析会提示被忽略的打击乐、钢琴音域以外的音、踏板及不完整配对。缺抬键的音按轨道末尾截断并提示。自动量化可能改变演奏细节；保存前请核对。导入长度以所选音符结尾补齐整小节，不保留文件末尾的纯空轨时长。详细模型与接口见 [ARCHITECTURE.md](./ARCHITECTURE.md)。

可从当前谱子的来源卡导出 JSON 或 MIDI。从自定义曲库迁移时优先用 JSON，以保留精确数据、指法与来源说明。修改变速 MIDI 的全曲 BPM 时，图形编辑器会将曲谱改为匀速；仅调整练习速度则按比例缩放既有变速。

## 反馈与练习记录

反馈包括音符准确度、起音节奏贴合度、逐音起音偏差及下一遍建议（平均偏差保存在导出分析数据中）；支持双手和弦的无序起音匹配。多音会计入准确度分母。节奏按固定的练习时间轴比较，未做自由速度跟随或设备延迟校准。

少于 3 个对齐音不计算节奏分数；没有收到音符时不生成虚构成绩。提前结束会说明未完成内容。切到后台或设备断开会终止当前采集，保留已录内容。回听是浏览器合成音色，不是电钢琴原始录音。

每遍最多采集 8192 个实际按键事件，达到上限时结束采集。

当前不评价手型、指法正确性、踏板、触键质量、音色或音乐表现力。指法显示是谱面提示，不代表系统能看到你使用的手指。

## 成长进度与 1–5 级学习路线

左侧「成长进度」包含三页：

- **练习概览**：7 / 30 / 90 天时长、自动采集与补记区分、练习天数、连续天数、每日音符表现及 12 周练习日历。点击日期可查看当天记录。
- **1–5 级路线**：每级 12 项，共 60 项自主学习目标；分基本练习、练习曲、复调与声部、乐曲表达、视奏与读谱、听觉与乐理。每项可记为还未开始、正在练习、等待复核、已经掌握，并留下本人评估或老师反馈。
- **我的练习计划**：关联应用曲谱或纸谱，安排学习阶段、目标速度、左右手及下一步。可以从计划直接打开对应曲谱练习，也可在练习室「关于这份谱子」中加入计划。

这是半拍独立整理的学习路线，**不是官方考级大纲或通过认证**。哈农条号与 599 教材进度不直接换算级别，内置曲谱是辅助基本功材料；实际备考曲目与要求需按选定机构、教材及老师安排核对。参考来源和口径详见 [LEARNING-ROADMAP.md](./LEARNING-ROADMAP.md)。

没有接琴时可以点击「补记练习」，记日期、分钟、练习内容与笔记。补记只影响时长和练习天数，不生成准确率。每周目标和目标等级可自行调整。首次使用没有虚构个人成绩；「看看进度示例」仅在内存展示，退出后不留下个人记录。

曲目计划的“近期表现可复核”要求：相同谱子内容和声部、全曲范围、达到目标速度，近 30 天最近 3 次完整采集均达到 95% 音符准确率和 85% 起音合拍率，至少分布在 2 天。它只是练习参考，包含屏幕琴键采集，不会自动完成等级清单或判断音乐表现力。

## 保存、备份与迁移

自定义谱子和新版练习记录存放在当前网站、当前浏览器的 **IndexedDB**，最近 100 次详细音符记录可在「练习记录」中查看。从 0.3 起另外保留长期摘要，超过 100 次后累计时长和成长统计仍保留；升级前已经删除的旧记录无法找回。旧版 `localStorage` 中的有效记录会一次性迁入新版记录，标记为旧版；原数据在清空历史前仍保留。界面偏好可能使用浏览器本地设置；没有云端账号数据库或跨设备同步。

换电脑、从部署地址转到 `localhost`、换浏览器配置或清理网站数据前：

1. 在曲谱库点击「备份我的全部谱子」，保留 JSON；也可逐首导出 JSON。
2. 在成长进度底部点击「备份进度」，保留目标、等级清单、计划、笔记和长期摘要。
3. 需要保留完整音符的某次练习，仍需从反馈单独导出练习 JSON。
4. 在新地址分别导入曲谱备份、恢复进度；重复恢复按记录 ID 去重。恢复前会说明设置替换范围，已有摘要以本机内容为准。

进度备份最多 128 MB / 200000 条摘要；导出前同样校验，避免生成自身无法导入的文件。曲谱恢复改变 ID 时，计划会按相同音乐内容尝试重新关联；不唯一或未导入对应谱时提示待关联。完整音符记录不包含在进度备份中，单次练习 JSON 仍用于离线留存，暂不支持批量恢复成详细历史。

源码包含程序和内置曲谱，不包含浏览器里的个人练习记录。私有部署网站与 `localhost` 属于不同来源，无法自动共享 IndexedDB。备份文件应另行妥善保存，导出曲谱也不会迁移浏览器设备权限。

全部演奏分析在浏览器中完成，代码没有演奏数据上传接口和第三方分析 SDK。托管平台的身份验证及普通访问日志属于网站基础设施。

## 验证与部署

本版已通过 92 项单元测试与练习、曲谱编辑、成长进度的浏览器流程验证，详情见 [VALIDATION.md](./VALIDATION.md)。执行 `npm test` 复跑自动化测试，覆盖曲谱校验、JSON / MIDI 导入导出、变速与分段、和弦与错漏音、输入事件和谱面准备等。浏览器验证用于检查实际操作流程与布局。**2026-09-22 用户反馈：实际钢琴连接后的练习流程通过**，琴型与浏览器版本未记录；该反馈及模拟 Web MIDI 验证不等于确认所有 Mac、驱动与琴型均已兼容。

运行 `npm run build` 后，把整个 `dist/` 部署到 HTTPS 静态托管的独立域名根目录，并保持平台登录 / 成员访问控制。内置资源无需外部 CDN；源码可独立本地运行，不依赖当前私有部署。

VexFlow 及 Bravura 资源位于 `public/vendor/`，许可证为 [VEXFLOW-LICENSE.txt](./public/vendor/VEXFLOW-LICENSE.txt)。Noto Sans SC 字体许可证位于 [OFL.txt](./public/fonts/OFL.txt)。曲谱数据的来源许可单独列于 [SOURCES.md](./SOURCES.md)，不与软件依赖许可证混为一谈。
